# Employment Statistics Analysis in Azerbaijan (1991–2024)

## 📊 Project Description
This project analyzes data from the State Employment Agency of Azerbaijan, covering the years **1991–2024**.  
The dataset includes information about:
- Individuals registered as unemployed,
- People who found employment,
- Participants in vocational training programs,
- Demand for labor to fill vacancies,
- People assigned and receiving unemployment benefits.

The main goal of the project is to **analyze trends in employment and unemployment** over time and **visualize the changes** using Python.

---

## 🧠 Technologies Used
- **Python (Pandas, Matplotlib)** — for data cleaning, transformation, and visualization  
- **Power BI** — for interactive dashboards 
- **PyCharm** — development environment  

---

## 📂 Dataset
The dataset contains three main columns:
1. `İnsanları fərqləndirən amillər` — Type of indicator (e.g., unemployed, employed, trained, etc.)  
2. `Tarix` — Year (1991–2024)  
3. `İnsanların sayı` — Number of people  

Source: *Manually compiled data from the State Employment Agency’s open statistics.*

---

## 📈 Analysis Overview
- Compared the number of unemployed individuals vs. employed individuals across years  
- Tracked changes in job placements and training participation  
- Identified periods of economic impact (e.g., sudden increases or drops in unemployment)  
- Visualized long-term employment trends using line charts
